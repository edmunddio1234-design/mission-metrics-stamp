# Mission Metrics Stamp

A phone-friendly web app that stamps the Mission Metrics logo onto a photo.

1. Open the app on your phone (tip: Share → **Add to Home Screen** so it works like an app).
2. Tap **Take photo** or **Choose from photos**.
3. The logo is stamped on right away. Adjust style, strength, size or spot if you like.
4. Tap **Save photo** → **Save Image** to put it in your Photos.

Photos are processed on the phone itself. Nothing is uploaded.

## Files
- `index.html` — the whole app
- `guide.html` — simple step-by-step for staff
- `manifest.webmanifest` — home-screen app settings
- `assets/logo-badge.png`, `logo-clean.png`, `logo-white.png` — the three logo styles
- `assets/icon-*.png` — home-screen icons

Static site, deployed on Vercel from `main`.
